About CareerCompass

AI-Assisted Skill Gap Analysis and Career Recommendation System

Project Introduction

In today's competitive job market, students and fresh graduates often face difficulties in identifying the skills required for their desired careers. Many learners spend time studying technologies without a clear learning path, making career preparation challenging.

CareerCompass is an intelligent web application that analyzes a user's current skills and career goals to provide personalized career guidance. By combining a structured database with AI-assisted recommendations, the system generates phased learning roadmaps, suggests hands-on portfolio projects, certifications, and learning resources.

Core Objectives

  • Develop a web-based career guidance and skill analysis system.
  • Provide secure user registration and role-based authentication (Student / Admin).
  • Create and manage user skill profiles with automated resume parsing.
  • Identify skill gaps between current skills and target careers with Radar visualizations.
  • Generate AI-assisted learning roadmaps and career recommendations.
  • Recommend relevant projects, certifications, and learning resources.
  • Allow users to track interactive learning milestones and progress.
  • Develop an admin module to manage career roles, learning resources, and user information.

Technologies Used

Python 3 (Flask) SQLite Database SQLAlchemy ORM Bootstrap 5.3 Chart.js (Radar Charts) Google Gemini / AI NLP Engine PyPDF (Resume Extractor)
